¿Qué significa cada estado?

  • Operativo — el componente responde con normalidad.
  • Con problemas — no responde o responde con errores; puede afectar a partes de la web.

La API principal tiene un servidor de respaldo: si el primero falla, la web intenta automáticamente con el segundo antes de mostrar un error. Si ves la nota "vía servidor de respaldo", significa que la web sigue funcionando con normalidad aunque por dentro se haya cambiado de servidor mientras se soluciona la incidencia en el principal.
